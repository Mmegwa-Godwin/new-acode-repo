# Ụbọchị — Igbo Heritage

**Preserving our heritage for generations.**

Ụbọchị is an offline-capable web calendar exploring Igbo market days, Nigerian observances, historical events, festivals, and community traditions.

## Features

- Four-day Igbo market cycle
- Date converter and monthly calendar
- National observances and historical records
- Festival and community directory
- Searchable cultural information
- Progressive Web App support

## Run locally

Serve the project directory using Python:

    python3 -m http.server 8000

Open `http://127.0.0.1:8000` in your browser.

## Cultural accuracy

Market-day cycles and festival customs can vary between communities. Community-specific information should be verified with knowledgeable local cultural custodians.
